⚙️ Kết nối YouTube Data API
Lưu ý: API key chỉ được lưu trong bộ nhớ trình duyệt trên thiết bị này. Hãy giới hạn key chỉ cho YouTube Data API v3 và thiết lập giới hạn website sau khi đưa ứng dụng lên mạng.

Tạo key tại Google Cloud Console → bật YouTube Data API v3 → Credentials (Thông tin xác thực) → Create credentials → API key. Hướng dẫn ở file README đi kèm.
